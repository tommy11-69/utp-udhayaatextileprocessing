# Udhayaa Textile Processing (UTP)

Modern, professional B2B website for Udhayaa Textile Processing.
Built with pure HTML, Vanilla JS, and Tailwind CSS.

## Features
- Custom responsive design tailored for B2B textile manufacturing.
- Integrated AI-generated contextual photography.
- Lightweight and fast with custom web components for layout (Header/Footer).
- Scroll-triggered animations and modern UX micro-interactions.
- Seamless "Request a Quote" form validation logic.

## Setup
No build tools required! Simply serve the directory using any local web server (e.g., Live Server, Python's `http.server`, etc.).
